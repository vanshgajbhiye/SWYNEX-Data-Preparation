# SWYNEX - Data Preparation

## Objective
The objective of this task is to prepare and clean a dataset
for data science analysis.

## Dataset
Students Performance Dataset

## Data Preparation Steps
- Loaded the dataset using Pandas
- Checked dataset dimensions
- Checked missing values
- Handled missing values
- Checked and removed duplicate records
- Verified data types
- Saved the cleaned dataset

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab

## Files
- SWYNEX_Data_Preparation.ipynb
- cleaned_student_data.csv
- README.md

## Key Learning
This task helped me understand the importance of data cleaning,
